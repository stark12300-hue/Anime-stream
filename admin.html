Add an episode / video source

Use the anime catalogue ID shown by MyAnimeList (MAL ID). Multiple sources can be added for the same anime, one at a time.

Bulk import catalogue

Paste JSON from an authorized API/feed or an export you have permission to use. This imports many anime and episode sources in one GitHub commit. It does not fetch or scrape Toonstream.

Format: {"anime":[{"mal_id":"numeric ID","title":"Anime title","sources":[{"name":"Episode 1","language":"Hindi Dub","url":"https://…","type":"auto"}]}]}. Source types: auto, video, embed. Maximum 500 anime records per batch.

Authorized HiAnime-compatible feed sync

Connect a JSON feed/API that you are authorized to access. Sync imports anime metadata and episode lists; playback URLs are imported only when the feed marks the feed and each source as authorized for distribution.

Configure HIANIME_FEED_URL in Render. Optional: HIANIME_FEED_TOKEN and HIANIME_SYNC_MINUTES (minimum 15). This does not scrape HiAnime webpages or bypass access controls.
